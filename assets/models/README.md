# Background removal model

`u2netp.onnx` is the lightweight U2NetP model, distributed by
[rembg](https://github.com/danielgatis/rembg) from its
[v0.0.0 model release](https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx).
The model originates from [U-2-Net](https://github.com/xuebinqin/U-2-Net) and
is licensed under Apache License 2.0; see [U-2-Net-LICENSE.txt](./U-2-Net-LICENSE.txt).
